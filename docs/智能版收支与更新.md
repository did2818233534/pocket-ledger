# 智能版收支和更新

智能版应用 ID 为 `cn.guga.ledger.smart`，原版数据与安装互不覆盖。记录使用原有正数金额与 `income` 分类表示收入；同步请求携带 `cashflow: 1`。同步服务只向声明支持的客户端返回收入，以免旧版将收入当支出或拒绝同步。未升级的同步服务会拒绝收入同步，手机保留本地记录并等待重试。

账本与统计默认显示支出；切换全部时，净额 = 收入 - 支出。截图服务仅对携带 `X-Cashflow: 1` 的新客户端在账单列表返回收入，旧客户端继续收到原格式。截图的识别结果需人工确认，不能保证所有银行版式准确。

## 发布智能版

安装包需要继续使用原有签名，versionCode 必须递增。先构建并校验包名、签名、版本、大小及 SHA-256。服务端 `/opt/pocket-ledger-ocr/releases/` 中先放入 `PocketLedgerSmart-版本号.apk`，然后原子替换 `latest.json`；OCR 容器只读挂载该目录并通过 HTTPS `/updates/` 提供文件。GitHub 使用 `smart-latest` 预发布标签及各自的 `latest.json`，APK URL 指向该标签的同名资源，避免影响原版正式 Release。手机优先访问服务器，连接或下载失败后访问该 GitHub 清单，并校验 APK 的 SHA-256、大小、包名、版本和签名。

升级 OCR 服务时保留 `X-Cashflow` 的旧客户端兼容行为；安装包与清单在两个源分别同步，确认哈希一致后再提供更新。代码与数据备份不包含在公开发布包中。
